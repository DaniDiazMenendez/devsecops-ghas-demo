# Politica de seguridad

## Reporte responsable

Si encuentras una vulnerabilidad en esta demo, abre un Security Advisory privado en GitHub o contacta al owner del repositorio. No publiques detalles tecnicos en issues publicos.

## Controles esperados

- Pull requests obligatorios antes de merge.
- CodeQL habilitado para analisis estatico.
- Dependabot alerts y security updates habilitados.
- Secret scanning con push protection.
- Revisores definidos por `CODEOWNERS`.

## Alcance

Este repositorio es una demo educativa. No procesa datos reales ni debe usarse como backend productivo.
